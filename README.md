# 🤖 Kylaash's Chatbot (Advanced UI)

A lightweight, visually appealing web-based chatbot built with pure HTML, CSS, and JavaScript.

## ✨ Features
- **Responsive & Modern UI:** Beautiful gradient backgrounds, soft shadows, and rounded chat bubbles.
- **Smart Keyword Matching:** Improved Regex-based NLP (Natural Language Processing) to detect word boundaries (prevents false matches like matching "this" for "hi").
- **Dynamic Responses:** Supports functional responses for real-time data like `time` and `date`.
- **Typing Indicators:** Animated bouncing dots for a natural AI conversation feel.
- **Auto-Scrolling:** Smooth auto-scrolling to the latest message.

## 🚀 How to Run Locally
1. Clone or download this repository.
2. Ensure all files (`index.html`, `style.css`, `script.js`, `chatbot-data.js`) are in the same folder.
3. Open `index.html` in any modern web browser (Chrome, Firefox, Safari).
